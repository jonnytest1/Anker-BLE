Anker BLE

Browser client

Scan and connect with Web Bluetooth. Runs FF09 confer, then subscribes for encrypted telemetry — no native app required.

You opened this page as a local file (file://). Chrome blocks scripts and Web Bluetooth that way. Serve it over HTTP instead:

In this folder run: python -m http.server 8765
Then open http://127.0.0.1:8765/

Or double-click serve.bat (Windows) / serve.sh (macOS/Linux).
